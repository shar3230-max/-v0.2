ПЛАНЕР v 0.2 — установка на Android
===================================
Приложение устанавливается как PWA (значок на главном экране, работает без интернета).
APK-файл собрать без Android-инструментов нельзя, поэтому используется установка через Chrome.

ВАРИАНТ 1. Самый простой (бесплатный хостинг, 5 минут)
1. Откройте https://app.netlify.com/drop (или любой другой статический HTTPS-хостинг: GitHub Pages, Cloudflare Pages).
2. Перетащите на страницу РАСПАКОВАННУЮ папку с файлами пакета:
   index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png
3. Получите адрес вида https://имя.netlify.app
4. На телефоне откройте адрес в Chrome -> меню (три точки) -> «Установить приложение» (или «Добавить на главный экран»).
5. Один раз откройте приложение с интернетом — после этого оно работает офлайн.

ВАРИАНТ 2. Если нужен именно APK
1. Разместите файлы как в варианте 1.
2. Откройте https://www.pwabuilder.com, вставьте адрес, нажмите Start -> Package for stores -> Android.
3. Скачайте пакет, установите APK на телефон (разрешите установку из неизвестных источников).

ПЕРЕНОС ДАННЫХ ПК <-> ТЕЛЕФОН
Настройки -> «Сохранить в файл» на одном устройстве; «Загрузить из файла» на другом
(можно заменить данные или объединить). Профиль и пароль на каждом устройстве свои.

ЗВУК И УВЕДОМЛЕНИЯ НА ТЕЛЕФОНЕ
- Включите звук в Настройки -> «Напоминания и звук». Нажмите «Проверить звук».
- Звук и вибрация срабатывают, пока приложение открыто на экране. Если Android «усыпил» приложение
  в фоне, напоминание придёт при открытии. Для надёжности отключите для Chrome/приложения
  экономию батареи (Настройки Android -> Приложения -> Chrome -> Батарея -> Без ограничений).
- Уведомления браузера: включите галочку в Настройки и разрешите уведомления.

ВАЖНО
Данные хранятся в браузере телефона. Не очищайте данные Chrome без резервной копии —
раз в неделю нажимайте «Сохранить в файл».
